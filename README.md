# One Letter: Coffee or Tea — A for Coffee

This entry answers the coffee-or-tea question with exactly one letter: **A**, for coffee. When run, `main.py` writes that single byte — no newline, no other content — to `/output/entry.txt`, which is all the competition's gate and judge require.
